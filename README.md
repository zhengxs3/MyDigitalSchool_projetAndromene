# Best Negotiator

Jeu multijoueur de négociation réalisé dans le cadre d'un projet académique à MyDigitalSchool.

## Technologies

- Front-end : React Native, Expo
- Back-end : CakePHP
- Base de données : MySQL

## Structure du projet

- `main` : landing page
- `app` : application front-end
- `backend` : API et back-end

## Mon rôle

Projet réalisé en équipe de 4 étudiants de différentes classes.
J'étais la seule développeuse du projet et j'ai assuré le développement de l'application et du back-end.
